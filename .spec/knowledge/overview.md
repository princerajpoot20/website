# Overview — asyncapi/website
> Created: 2026-05-25 | Updated: 2026-05-25

## What this project is

The public asyncapi.com site. Next.js 15 Pages Router, MDX-based docs and blog, TypeScript, Tailwind. Deployed to Netlify.

## Folder layout (top level)

| Path | Role |
|------|------|
| `pages/` | Next.js routes (Pages Router) |
| `components/` | React components, grouped by feature area |
| `config/` | JSON data files — mix of manually-authored and auto-generated |
| `scripts/` | Build-time and workflow-invoked scripts |
| `netlify/` | Netlify functions + edge functions |
| `markdown/` and `docs/` | Docs source (MDX) |
| `public/` | Static assets |
| `tests/` | Jest unit tests, mirrors `scripts/` structure |
| `cypress/` | E2E tests |
| `.github/workflows/` | ~30 workflows for CI, releases, weekly automation |

## Conventions

- **Config JSON files** in `config/` — some human-authored (e.g. `tools-manual.json`, `MAINTAINERS.json`), some machine-generated by weekly workflows (e.g. `tools-automated.json`, `meetings.json`).
- **Weekly workflows** (`regenerate-tools.yml`, `regenerate-meetings-and-videos.yml`) open PRs with regenerated JSON. These PRs require maintainer approval before merge.
- **Tests** live in `tests/` mirroring `scripts/` layout. Jest is the runner.
- **Linting**: ESLint + Prettier, enforced on PR.
